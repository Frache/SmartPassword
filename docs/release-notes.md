## Installation

1. Download **SmartPassword.exe** below.
2. Put it in its own folder, for example `%LOCALAPPDATA%\Programs\SmartPassword\`, and start it.

Full step-by-step guide, including how to update and how to verify the download: [docs/INSTALL.md](https://github.com/Frache/SmartPassword/blob/main/docs/INSTALL.md)

## Updating

If you already have SmartPassword 1.0.0 or later, it will offer this version on the unlock screen. Click **Opdater nu**.

## Files

| File | What it is |
|---|---|
| `SmartPassword.exe` | The program for Windows 10/11 (x64). No installation or .NET needed. |
| `SmartPassword.exe.sha256` | Checksum the app uses to verify an update before installing it. |
